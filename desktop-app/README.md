# ヒツジの執事「メリー」 — デスクトップ AI キャラクター

デスクトップに常駐し、**音声とチャット**で会話できる AI マスコットです。
かつてのソフトバンクの「羊のしつじ」のように、画面のすみでご主人さまをそっと支えます。
頭脳には **Claude Sonnet 5** を搭載しています。

## できること

- 🐑 **デスクトップマスコット** — 透明・枠なし・常に最前面のウィンドウに、ふわふわ浮かぶ執事ヒツジ。ドラッグで好きな位置へ。まばたき・呼吸・口パクのアニメーション付き。
- 💬 **チャット会話** — 吹き出しにテキストを打ち込むと、執事口調でストリーミング応答。
- 🎙 **音声で話しかける** — マイクボタンで音声入力（Web Speech API / 日本語）。
- 🔊 **音声で応答** — 返答を日本語で読み上げ（OS の音声合成）。話すと口が動きます。
- 🎩 **執事の人格** — 丁寧で上品、あたたかい執事キャラクターとして応答します（`src/persona.js`）。

## 必要なもの

- [Node.js](https://nodejs.org/) 18 以上
- Anthropic の **API キー**（[コンソール](https://console.anthropic.com/settings/keys)で取得）

## セットアップ

```bash
cd desktop-app
npm install
npm start
```

初回起動時、ヒツジを **右クリック → 「設定」** から API キーを登録してください。
（環境変数 `ANTHROPIC_API_KEY` が設定されていれば、そちらが優先されます。）

## 使い方

| 操作 | 動作 |
| --- | --- |
| ヒツジをドラッグ | 位置を移動 |
| ヒツジを右クリック | メニュー（会話リセット / 設定 / 終了） |
| ヒツジをダブルクリック | 入力欄にフォーカス |
| 🎙 ボタン | 音声入力の開始 / 停止 |
| ➤ ボタン / Enter | 送信 |

設定画面では、モデルの選択・音声の ON/OFF・読み上げ速度・声の高さ・使用する音声を変更できます。

## 構成

```
desktop-app/
  src/
    main.js              Electron メインプロセス（ウィンドウ・IPC・会話ループ）
    preload.js           レンダラーへ公開する安全な API（contextBridge）
    persona.js           執事ヒツジの人格（システムプロンプト）
    claude.js            Claude Sonnet 5 とのストリーミング会話ラッパー
    config.js            設定（API キー・音声）の保存/読込
    renderer/
      mascot.html/css/js マスコット本体＋チャット UI（SVG キャラクター）
      settings.html/css/js 設定画面
```

## 技術メモ

- **モデル**: 既定は `claude-sonnet-5`。マスコットの応答速度を優先し `thinking: { type: "disabled" }` で呼び出しています。設定画面から Opus 4.8 / Haiku 4.5 にも切り替え可能です。
- **ストリーミング**: `client.messages.stream()` を使い、テキスト差分を IPC でレンダラーへ逐次送信して吹き出しに表示します。
- **プロンプトキャッシュ**: 固定のシステムプロンプトに `cache_control` を付与しています。
- **会話履歴**: メインプロセスで直近 20 ターンを保持します（`src/claude.js`）。
- **API キーの扱い**: キーはこの端末の userData 内 `config.json` に平文保存されます。共有端末ではご注意ください。

## 制限・既知の注意点

- **音声入力（STT）** は Chromium の Web Speech API を利用します。環境によってはネットワーク接続やマイク権限が必要で、うまく動かない場合があります。その際はチャット入力をご利用ください。
- **音声合成（TTS）** は OS の音声を使います。日本語音声が入っていない環境（一部の Linux 等）では読み上げされないことがあります。Windows / macOS には標準で日本語音声が含まれます。
- 透明・最前面ウィンドウの見え方は OS によって多少異なります。
